Advanced Note (Siv3D)
Siv3Dを活用した、構造的で高速な動作を実現するシングルウィンドウ型ノートアプリケーションです。
AIとの共同開発プロセスにより、短期間で高機能なUIとデータ永続化（JSON）を実装しました。

🚀 特徴
マルチタブ管理: 複数のノートをタブ形式で切り替え可能。

動的な視認性制御: 背景色に合わせてテキストカラー（白/黒）を自動計算（輝度判定）。

セーフティ削除機能: 5秒間のUndo（元に戻す）機能と確認ダイアログによる誤操作防止。

高速な検索: ノートのタイトルおよび本文からのリアルタイムフィルタリング。

自動保存: 編集後、操作が一定時間停止した際に自動でJSONへ書き出し。

カスタマイズ: ノートごとのカラー変更、フォントサイズ調整機能。

🛠 技術スタック
Language: C++20

Framework: OpenSiv3D (v0.6.x 以降推奨)

Data Format: JSON (Siv3D JSONパーサー)

Design Pattern: オブジェクト指向に基づいた状態管理

📋 セットアップ
OpenSiv3D をインストール済みの環境でプロジェクトを作成します。

Main.cpp に本リポジトリのソースコードをコピーします。

ビルドして実行してください。

ショートカットキー
Ctrl + S: 手動保存

Ctrl + F: 検索バーへフォーカス

Ctrl + Tab: ノートの切り替え

📐 設計思想（自灯明の体現）
このアプリケーションは、依存を最小限にし、論理的な自己完結性を高める「自灯明」のエンジニアリング精神に基づいて設計されています。

ロジックの分離: 描画（UI）とデータ処理（Save/Load）の明確な分離。

拡張性: Note 構造体へのプロパティ追加により、容易に機能拡張が可能。
